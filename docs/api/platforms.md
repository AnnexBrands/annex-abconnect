# Platforms

```{eval-rst}
.. autoclass:: ab.api.endpoints.platforms.PlatformsEndpoint
   :members:
   :undoc-members:
```

```{note}
Platforms are new in the **migrated Catalog schema**. Production had not
migrated as of this release, so these calls fail against it — the platform
surface does not exist on the pre-migration API.
```

A platform is an external marketplace a catalog or lot is published to. The
platform ID plus an external ID is what replaced the retired
`Catalogs.CustomerCatalogId` and `Lots.CustomerItemId` columns: a catalog
carries {class}`~ab.api.models.platforms.CatalogPlatformDto` entries with a
`platform_catalog_id`, and a lot carries
{class}`~ab.api.models.platforms.LotPlatformDto` entries with a
`platform_item_id`. Because the association is a join row, one catalog or lot
can now hold a different external ID per platform — something the single
obsolete column could not express.

## Methods

### create

`POST /Platform` — Create a new platform.

**Returns:** {class}`~ab.api.models.platforms.PlatformDto`

```python
from ab import ABConnectAPI

api = ABConnectAPI(env="staging")
platform = api.platforms.create(data={
    "name": "Sample Auction Platform",
    "partnerId": 77,
    "isActive": True,
})
```

```{note}
`partner_id` must be non-zero — the API answers `400 PartnerId is required`
for `0`.
```

### list

`GET /Platform` — List platforms with optional filters (paginated).

**Returns:** {class}`~ab.api.models.shared.PaginatedList`\[{class}`~ab.api.models.platforms.PlatformDto`\]

```python
platforms = api.platforms.list(page_number=1, page_size=25)
platforms = api.platforms.list(partner_id=77, is_active=True)
```

### get

`GET /Platform/{id}` — Get a platform by ID.

**Returns:** {class}`~ab.api.models.platforms.PlatformDto`

```python
platform = api.platforms.get(1)
```

### update

`PUT /Platform/{id}` — Update a platform.

**Returns:** {class}`~ab.api.models.platforms.PlatformDto`

```python
api.platforms.update(1, data={
    "name": "Sample Auction Platform",
    "partnerId": 77,
    "isActive": False,
})
```

### delete

`DELETE /Platform/{id}` — Delete a platform.

```python
api.platforms.delete(1)
```
